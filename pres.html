1. Visão Geral da Arquitetura

Estruturação completa e responsabilidades dos componentes do programa.

Modelo de Execução Monolítico em Console

  • A aplicação roda em loop contínuo sobre o terminal utilizando codificação UTF-8.
  • Inicia carregando os arquivos físicos para a memória antes de interagir com o usuário.
  • Divide suas funções em 4 grandes pilares: Estruturas de Dados, Operações do Menu, Persistência e Utilitários.

Namespaces e Dependências Importadas

using System;
using System.Collections.Generic;
using System.Globalization;
using System.IO;
using System.Reflection;

Importação de suporte a coleções dinâmicas (List<T>), formatação regional (CultureInfo) e manipulação de arquivos (File, StreamWriter).

2. Modelagem de Dados: struct Produto

Representação em memória dos itens do estoque da loja.

Definição da Struct

struct Produto
{
    public string Nome;
    public string Categoria;
    public int Quantidade;
    public decimal Preco;
}
  • Uso do tipo valor struct para alocação eficiente na pilha (stack).
  • Tipo decimal para o preço, evitando imprecisões de ponto flutuante em valores monetários.

Sobrescrita de ToString()

public override string ToString()
{
    return "Nome: " + Nome +
           " | Categoria: " + Categoria +
           " | Estoque: " + Quantidade +
           " | Preço: " + Preco;
}

Centraliza a formatação visual do produto para exibição rápida em listagens e consultas.

3. Modelagem de Dados: struct Venda

Registro do histórico de transações efetuadas pelo sistema.

Campos da Venda

struct Venda
{
    public string NomeProduto;
    public string Categoria;
    public int Quantidade;
    public decimal PrecoUnitario;
    public decimal Total;
    public string Data;
}
  • Grava o estado exato da transação no momento em que a venda foi realizada.
  • Guarda a data e hora formatadas como texto para consulta nos relatórios.

Formatador de Transação

public override string ToString()
{
    return Data + " | " + NomeProduto +
           " | Categoria: " + Categoria +
           " | Quantidade: " + Quantidade +
           " | Total: " + Total;
}

Gera a linha resumida que é impressa no relatório de vendas.

10. Módulo de Busca: ConsultarProduto()

Pesquisa parcial de itens por nome sem diferenciação de caixa.

Algoritmo de Busca Parcial

for (int i = 0; i < produtos.Count; i++)
{
    if (produtos[i].Nome.IndexOf(
        nome, 
        StringComparison.OrdinalIgnoreCase) >= 0)
    {
        Console.WriteLine(produtos[i]);
        encontrou = true;
    }
}

Destaques de Funcionamento

  • IndexOf: Permite encontrar termos parciais (ex: buscar "RTX" encontra "Placa RTX 3060").
  • OrdinalIgnoreCase: Ignora maiúsculas e minúsculas na busca.
  • Exibe múltiplos produtos caso a busca coincida com mais de um item.

Procedimento seguro para exclusão de peças do cadastro.

Confirmação de Segurança

Console.WriteLine(produtos[indice]);
Console.Write("Confirma a exclusao? (S/N): ");

Exibe os dados do item localizado antes de solicitar a confirmação explícita.

if (resposta == "S")

14. Relatório e Inteligência: RelatorioVendas()

Consolidação do faturamento geral e agrupamento por categoria.

for (int i = 0; i < vendas.Count; i++) {
    Console.WriteLine(vendas[i]);
    totalGeral += vendas[i].Total;

        categorias.Add(vendas[i].Categoria);

Soma o faturamento total e cria a lista de categorias que tiveram vendas.

Cálculo do Faturamento por Categoria

for (int i = 0; i < categorias.Count; i++) {
    decimal totalCategoria = 0;
    for (int j = 0; j < vendas.Count; j++) {
        if (vendas[j].Categoria == categorias[i])

}

15. Persistência de Dados: Método Salvar (Linha 360+)

Escrita de produtos e vendas no formato delimitado por pipe (|).

SalvarProdutos() em Detalhes

using (StreamWriter escritor = 
    new StreamWriter(arquivoProdutos, false))
{
    for (int i = 0; i < produtos.Count; i++)
    {
        Produto p = produtos[i];
        escritor.WriteLine(
            LimparCampo(p.Nome) + "|" +
            LimparCampo(p.Categoria) + "|" +
            p.Quantidade + "|" +
            p.Preco.ToString(CultureInfo.InvariantCulture));
    }
}

Pontos Críticos de Arquitetura

  • Bloco using: Garante liberação do arquivo na conclusão da escrita.
  • Sobrescrita (false): O segundo parâmetro false substitui o conteúdo do arquivo com os dados atualizados.
  • InvariantCulture: Garante formato numérico universal (ex: 1500.50 com ponto).

16. Persistência de Dados: Método Carregar (Linha 360+)

Leitura e conversão dos arquivos de texto para objetos em memória.

CarregarProdutos() em Detalhes

if (!File.Exists(arquivoProdutos)) return;
string[] linhas = File.ReadAllLines(arquivoProdutos);

for (int i = 0; i < linhas.Length; i++) {
    string[] partes = linhas[i].Split('|');
    if (partes.Length == 4 &&
        int.TryParse(partes, out int qtd) &&
        decimal.TryParse(partes, NumberStyles.Number,
            CultureInfo.InvariantCulture, out decimal preco)) {
        // Popula Produto e adiciona em produtos
    }
}

Tratamento de Exceções e Falhas

  • File.Exists: Aborta a leitura com segurança se o arquivo ainda não tiver sido criado.
  • Split('|'): Quebra a linha nos campos originais.
  • int.TryParse e decimal.TryParse: Previnem travamentos do programa caso o arquivo texto seja modificado incorretamente.

17. Sanitização e Validação de Entradas

Defesas contra erros de digitação e corrupção de arquivos.

LimparCampo()

static string LimparCampo(string texto) {
    return texto.Replace("|", "/")
                .Replace("\r", " ")
                .Replace("\n", " ");
}

Substitui o caractere | por / e remove quebras de linha para evitar corrupção nos dados.

LerInteiro()

while (true) {
    Console.Write(mensagem);
    if (int.TryParse(Console.ReadLine(), 
        out valor) && valor >= minimo 
        && valor <= maximo)
        return valor;
    Erro("Digite um inteiro valido.");
}

Força a entrada correta de um número dentro dos limites esperados.

LerDecimal()

entrada = entrada.Trim()
                 .Replace(',', '.');
if (decimal.TryParse(entrada, 
    NumberStyles.Number, 
    CultureInfo.InvariantCulture, 
    out valor) && valor >= minimo)
    return valor;

Substitui vírgulas por pontos aceitando qualquer padrão do usuário.

18. Interface de Console e Estilização Visual

Padronização do feedback em cores no terminal.

Funções de Estilo Visual

  • Titulo(): Imprime o cabeçalho decorado em Amarelo (ConsoleColor.Yellow).
  • Erro(): Exibe alertas de falha em Vermelho (ConsoleColor.Red).
  • Sucesso(): Exibe mensagens de confirmação em Verde (ConsoleColor.Green).
  • Console.ResetColor(): Garante a restauração das cores padrão do terminal após cada mensagem.

Controle de Cadência com Pausar()

static void Pausar()
{
    Console.WriteLine(
        "\nPressione ENTER para continuar...");
    Console.ReadLine();
}

Segura a tela permitindo que o usuário analise o relatório ou resultado antes de retornar ao menu principal.
